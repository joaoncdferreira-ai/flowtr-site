# Flowtr store visuals

Updated: 28 July 2026

## Current reference set

The files in `public/app-current` show the current Flowtr interface:

- `mapa-inicial.jpg` — map and main navigation;
- `revisao-corrida.jpg` — run review;
- `reclamar-territorio.jpg` — closed area ready to claim;
- `opcoes-partilha.jpg` — sharing formats;
- `video-a-renderizar.jpg` — in-app video creation;
- `video-3d-inicio.png` and `video-3d-percurso.png` — current 3D video;
- `video-resultado.png` — final share result.

These files are suitable for the website and for choosing the store narrative.
The JPEG simulator captures are only 368 × 800 px, so they are **not** the final
files to upload to App Store Connect or Google Play.

## Final store capture

Before submission, recapture the chosen screens from the release candidate at
the native device resolution. Use a clean test account, keep the language in
Portuguese (Portugal), remove personal data and use one coherent sample run
across the set.

Recommended story:

1. Start from the shared 3D map.
2. Run and close a valid area.
3. Claim the territory.
4. Check the result in the Diary or rankings.
5. Share the 3D run video.

The old files in `public/prints-site` and `public/screenshots-clean` are kept
only as an archive. They must not be mixed with the current interface.
